## 🚀 How to Deploy to GitHub Pages in 2 Minutes

This website is built with zero server-side build steps. You can deploy it directly:

### Method A: Uploading via Browser (GitHub.com)
1. Go to your repository on GitHub: `https://github.com/fahimgalib/fahimgalib.github.io`
2. Click **Add file** -> **Upload files**.
3. Drag and drop all files from this folder (`index.html`, `css/`, `js/`, `img/`).
4. Click **Commit changes**.
5. Go to **Settings** -> **Pages**.
6. Under **Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
7. Your site is instantly live at: `https://fahimgalib.github.io/`!

### Method B: Using Git in Terminal
```bash
git add .
git commit -m "Revamp website: Bespoke non-AI design, SEO pricing module, recent projects"
git push origin main
```
